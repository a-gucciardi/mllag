# Syllabus for Certificate of Advanced Studies in Data Engineering and Applied Data Science

## Module 1: Introduction to Data Science

### Description:
This module provides a comprehensive understanding of project management principles tailored to data science and engineering. It equips participants with skills to plan, execute, and deliver successful data-driven projects.

### Topics & Learning Objectives:

#### Einführung (Introduction)
- **Understand data's role in modern business**
  - Learn about data value creation
  - Recognize data-driven business transformation

#### Content Overview:
- Facts about data generation and growth
- Data volume in everyday life
- Business impact of data
- Data-driven business models (DGGM)
- Business Model Canvas
- Digital transformation challenges

#### Hands-on/Exercises:
- Create a Business Model Canvas (BMC) or Data-Driven Business Model (DGGM) from a professional environment.

#### Tools Used:
- Azure DevOps, Azure SQL, Databricks, Power BI, GitHub, Jira

#### Use Cases
- **Understand practical applications of Data Science**
  - Learn from real-world implementations
  - Recognize how companies monetize data

#### Content Overview:
- Industry examples: Autonomous driving, Fraud detection, Logistics, Medicine 
- Detailed case studies: OYM (sports performance), PlaySuisse (streaming), Modern data warehouse examples

#### Hands-on/Exercises:
- Group work: Define a use case from your business environment.

#### Tools Used:
- Azure DevOps, Azure SQL, Databricks, Power BI, GitHub, Jira

### Project Management
- **Understand project management approaches for data science**
  - Learn agile methodologies
  - Comprehend roles and responsibilities

#### Content Overview:
- Traditional vs. Agile project management
- SCRUM framework and ceremonies
- Project organization structures
- Team roles and responsibilities
- DevOps and DataOps concepts

#### Hands-on/Exercises:
- Conduct a project retrospective and document lessons learned.

#### Tools Used:
- Azure DevOps, Azure SQL, Databricks, Power BI, GitHub, Jira

### Requirements Engineering
- **Understand requirements engineering in data science**
  - Learn agile requirements process
  - Master use case and user story creation

#### Content Overview:
- Traditional vs. Agile requirements engineering
- 5 steps in agile requirements engineering
- Use cases vs. user stories
- Definition of Done 
- INVEST criteria

#### Hands-on/Exercises:
- "Whisper Game" exercise 

#### Tools Used:
- N/A (exercise-based)

### Data Platforms & History
- **Understand data platform evolution**
  - Learn about different database types
  - Comprehend historical development

#### Content Overview:
- Evolution of data storage (1960s-present)
- Database types and their progression
- Data Platform zones: Landing, Raw, Refined, Usage Optimized, Archive, Sandbox Zones
