CAS Machine Learning – Syllabus 

 

The CAS Machine Learning at HSLU is a hands-on, practice-oriented program designed for professionals looking to deepen their understanding of machine learning. Participants gain practical skills in building, training, and evaluating machine learning models using real-world data. The course covers key concepts, algorithms, and tools. Ideal for individuals aiming to integrate machine learning into their work, it combines theory with practical exercises to ensure participants can apply their knowledge immediately. 

The program emphasizes a strong hands-on approach, integrating practical exercises into every topic to ensure participants can immediately apply their knowledge to real-world scenarios.  

Each module includes guided labs, coding challenges, and case studies using industry-relevant tools and datasets. Participants work with popular frameworks such as TensorFlow, and Scikit-learn, enabling them to implement machine learning models from scratch, optimize algorithms, and interpret results effectively. These practical sessions help participants understand not only the technical aspects of machine learning but also how to handle challenges such as data preprocessing, overfitting, and model evaluation. 

The CAS Machine Learning comprises 11 modules. 

 

Module 1: Introduction to Python and Data Analysis Ecosystem 

Environment Setup 

Introduction to Anaconda distribution and Package management 

Navigating the interface, creating and running Jupyter Notebooks 

Introduction to Python Fundamentals 

Basic Python Syntax, Data Types & Structures, Control Flow, Functions 

Data Handling with Pandas (Data I/O, Data Cleaning & Preparation, Aggregation & Grouping) 

Numerical Computing with NumPy (Array Creation & Manipulation, Matrix operations) 

Visualization with Matplotlib/Seaborn (Basic Plotting & Customization, Exploratory Data Analysis) 

Hands-on Project 

Choosing a suitable dataset and formulating initial ideas 

Applying learned techniques for data cleaning and preparation 

Plotting data to extract meaningful insights 

Project presentation on Saturday afternoon, showcasing findings and applied techniques 

 

 

Module 2: Supervised Machine Learning 

Regression Modelling 

Data Preparation (e.g. imputation), Linear Regression, Loss Functions, Feature Selection & Scaling (numerical stability), Gradient Descent (Basics of optimization, iterative parameter updates) 

Classification Essentials 

Logistic Regression, Classification Loss Functions, Evaluation Metrics (precision, recall, F1-score, ROC AUC) and their usage, Imbalanced Classes (skewed class distributions, Multiclass Classification 

Model Generalization and Performance 

Bias-Variance Trade-off, Regularisation (concept of overfitting), Model Selection Principles, Cross-Validation (robust performance estimation), Hyperparameter Tuning (systematic search for model parameters), Data Leakage 

Beyond Linear Models 

Non-Linear Algorithms (overview of decision trees, SVMs, etc.), Ensemble Methods (Introduction to bagging, boosting, and random forests) 

 

Module 3: Deep Learning 

Foundations of Deep Learning 

Historical background and objectives of Deep models, Perceptrons & Activation Functions (ReLU, Sigmoid, etc.), Backpropagation (training neural networks) 

Neural Network Architecture  

Data & Model Pipeline: Steps from data loading, preprocessing (normalization, reshaping inputs) to training and evaluation  

Fully Connected Networks (building Neural Networks using Keras), choosing Model Parameters (number of hidden layers, neurons, and activation functions), Effect of Architecture Changes (performance differences)  

Convolutional Neural Networks (CNNs)  

Basic CNN Architecture (convolutional layers, pooling layers, and feature extraction),  

Model Training & Evaluation/Monitoring (running training epochs, evaluating metrics, plotting training/validation loss curves to detect over/underfitting) 

 Hyperparameter Tuning (adjusting dropout rates, learning rates, convolutional filters, and dense layer sizes) 

 

 

 

 

Module 4: Computer Vision 

Foundations of Image Analysis 

Image Formats & Types, Image Features & Representations 

Detailed understanding of convolutions, kernels, and filters (with code examples) 

Data augmentation techniques 

Metrics and Evaluation in Computer Vision  

Image Classification Metrics, Image Localization & Intersection over Union  

Advanced NN Architectures for Computer Vision 

Pre-trained Models (understanding and adapting model architectures for new tasks) 

Transfer Learning (leveraging pre-trained models (e.g., VGG 16, ResNet) for improved performance) 

 

Module 5: Generative AI 

Core Concepts of Generative Models 

Autoencoders (dimensionality reduction, reconstruction tasks), Variational Autoencoders (VAEs) (generating new data from learned distributions), Generative Adversarial Networks (GANs) (Adversarial training setup (generator vs. discriminator), concepts and training dynamics), Diffusion Models 

Practical Considerations 

Training & Limitations (insights into stability issues, mode collapse in GANs, and other training challenges), Implementation Details (code examples, best practices for training and tuning generative models), Evaluation (simple metrics and qualitative assessment of generated data) 

 

Module 6: Natural Language Processing 

Foundations of NLP 

Text Mining Basics (tokenization, stemming, lemmatization, stopword removal), Text Similarity (cosine similarity, word overlap) 

Advancements in NLP 

Word Embeddings (representing words as vectors, e.g., Word2Vec, GloVe), Text Generation with AI (Language models, Generated text) 

 

Module 7: Unsupervised Learning  

Clustering: K-means, hierarchical clustering  

Dimension reduction: principal component analysis (PCA),  t-distributed stochastic neighbouring. 

 

Module 8: Transformers and Large Language Models 

Environment Setup 

Managing models, datasets, and experiments in the HuggingFace ecosystem 

Foundations and Concepts 

Transformers (understanding the architecture and attention mechanism, Prompt Engineering (techniques to guide LLMs to produce desired outputs),  

Advanced Techniques and Tools 

Retrieval Augmented Generation (RAG) (integrating knowledge retrieval with generation, using tools like LangChain, LlamaIndex), Claude.ai Model (exploration of using Claude for generation tasks), Fine-Tuning on Specialized Data (adapting a Gemma Model to achieve domain-specific performance) 

 

Module 9: Keras Introduction 

Foundations of Keras 

Keras Overview (as a framework built on TensorFlow), Training Workflow (end-to-end process), Software & Hardware Requirements (GPU/TPU usage for acceleration) 

Core Concepts 

Built-in Functions & Models, Model Compilation (loss functions, optimizers, and metrics), APIs & Customization (functional vs. sequential API, customizing layers and architectures) 

Advanced Techniques 

Custom Training Loops, manually computing Gradients, Flexible experimentation 

 

Module 10: Reinforcement Learning 

Foundations and Concepts 

Terminology, Tasks & Methods (defining states, actions, rewards, episodes; exploring common RL tasks, e.g., grid worlds, games) 

Approaches 

Model-Based & Model-Free, Policy-Based & Value-Based Methods (understanding how agents learn policies directly or estimate state/action values) 

 

Applications 

Real-world use cases (robotics, recommendation systems, resource allocation) 

Introduction to TF-Agents library for RL tasks 

Practical Training & Evaluation (running experiments, analysing learning curves, tuning hyperparameters) 

 

Module 11: Machine Learning Operations (MLOps) 

Foundations & Principles 

core concepts and objectives of MLOps, Challenges in Model Deployment, Work Environments & Tools (introduction to Codespaces, Docker containers) 

Infrastructure & Platforms 

Tracking, registering, and managing model versions with MLflow, Data Processing Modes (request-response, batch, and stream processing architectures) 

Data Management & Quality 

Model Drift (detecting and responding to changes in data distribution), Data Orchestration & Validation, Feature Stores 

 

The CAS Machine Learning program concludes with participants equipped with a comprehensive understanding of machine learning concepts, methods, and tools, reinforced by practical, hands-on experience. Each module is designed to build upon the last, offering both foundational knowledge and advanced techniques applicable across a variety of domains. From Python programming to neural networks, computer vision, NLP, and MLOps, participants gain the skills necessary to handle complex data challenges and deploy robust machine learning solutions. This syllabus highlights the program's goal of blending theory with real-world application. 

This prepares graduates to confidently tackle challenges in data science, AI, and beyond, applying their expertise to drive innovation in their respective fields. 

Note that the content can change at any moment and the topic listed here are not guaranteed.
