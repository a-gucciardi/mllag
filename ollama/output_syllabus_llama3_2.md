**Certificate of Advanced Studies in Data Engineering and Applied Data Science Program**

**Module 1: Introduction to Data Science**

* Topics:
	+ Data's role in modern business
	+ Data value creation
	+ Business impact of data
	+ Digital transformation challenges
* Learning Objectives:
	+ Understand the importance of data-driven decision making
	+ Learn about different types of data and their applications
	+ Recognize the challenges of digital transformation
* Content:
	+ Business Model Canvas (BMC) or Data-Driven Business Model (DGGM)
	+ Industry examples: Autonomous driving, Fraud detection, Logistics, Medicine
	+ Detailed case studies: OYM (sports performance), PlaySuisse (streaming), Modern data warehouse examples
* Hands-on/Exercises:
	+ Define a use case from your business environment using Azure DevOps, Azure SQL, Databricks, Power BI, GitHub, Jira
	+ Conduct a project retrospective and document lessons learned
* Tools: Azure DevOps, Azure SQL, Databricks, Power BI, GitHub, Jira

**Module 2: Data Engineering Introduction**

* Topics:
	+ Git basics
	+ Database types and their applications
	+ Cloud environment setup
* Learning Objectives:
	+ Understand the basics of version control using Git
	+ Learn about different database types and their use cases
	+ Master cloud environment setup using Azure
* Content:
	+ Git history and purpose
	+ Goals of Git (speed, non-linear development, distributed)
	+ Basic workflow (add, commit, push, pull)
* Hands-on/Exercises:
	+ Set up a GitHub/GitHub environment
	+ Work with multiple databases using NoName Company and Azure DevOps
	+ Understand cloud environment setup using Azure Portal and MFA
* Tools: Git, GitHub, Python (pandas, sklearn)

**Module 3: Data Engineering. Part 1**

* Topics:
	+ Data engineering definition and role
	+ Machine learning pipeline components
	+ Data platform and zones
* Learning Objectives:
	+ Understand the definition and role of data engineers
	+ Learn about machine learning pipeline components
	+ Understand different zones in a data platform and their purposes
* Content:
	+ Definition of data engineering and its role in maintaining data infrastructure
	+ Relationship between data engineering and machine learning
	+ Data platform capability map and different zones (Landing Zone, Raw Zone, Refined Zone, etc.)
* Hands-on/Exercises:
	+ Work with Git commands using GitHub and Python (pandas, sklearn)
	+ Understand NoSQL database types and their applications
	+ Visualize data architectures using different tools
* Tools: GitHub, Python (pandas, sklearn)

**Module 4: Python Introduction**

* Topics:
	+ Core principles of programming in Python
	+ Data manipulation and analysis using pandas and NumPy
* Learning Objectives:
	+ Understand the basics of programming in Python
	+ Learn about data manipulation and analysis using pandas and NumPy
* Content:
	+ Core principles of programming in Python
	+ Data manipulation and analysis using pandas and NumPy

**Hands-on Projects**

* Throughout the program, participants will work on hands-on projects that integrate the concepts learned in each module.
