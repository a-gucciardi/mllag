**Syllabus: Certificate of Advanced Studies in Data Engineering and Applied Data Science**

**Module 1: Introduction to Data Science**

* Topics:
	+ Introduction to data science
	+ Business impact of data
	+ Data-driven business models
	+ Project management approaches for data science
	+ Requirements engineering in data science
	+ Data platforms and history
* Learning Objectives:
	+ Understand the role of data in modern business
	+ Learn about data value creation and data-driven business transformation
	+ Recognize the importance of project management and requirements engineering in data science
	+ Comprehend the evolution of data storage and database types
* Content:
	+ Facts about data generation and growth
	+ Data volume in everyday life
	+ Business impact of data
	+ Data-driven business models (DGGM)
	+ Business Model Canvas
	+ Digital transformation challenges
	+ Traditional vs. Agile project management
	+ SCRUM framework and ceremonies
	+ Project organization structures
	+ Team roles and responsibilities
	+ DevOps and DataOps concepts
* Hands-on/Exercises:
	+ Create a Business Model Canvas (BMC) or Data-Driven Business Model (DGGM) from professional environment
	+ Group work: Define a use case from your business environment
	+ Conduct a project retrospective and document lessons learned
	+ "Whisper Game" exercise
* Tools:
	+ Azure DevOps
	+ Azure SQL
	+ Databricks
	+ Power BI
	+ GitHub
	+ Jira

**Module 2: Data Engineering Introduction**

* Topics:
	+ Git introduction
	+ GitHub setup
	+ NoName Company/Database setup
	+ Cloud environment
* Learning Objectives:
	+ Understand Git's history and purpose
	+ Learn about distributed vs centralized version control
	+ Master basic Git workflow
	+ Learn to set up Git/GitHub environment
	+ Understand GitHub student benefits
	+ Understand the company structure and learn to work with multiple databases
	+ Master database connections
* Content:
	+ History of Git
	+ Goals of Git (speed, non-linear development, distributed)
	+ Git snapshots vs other VCS
	+ Basic workflow (add, commit, push, pull)
	+ Branches & pull requests concepts
	+ Installation instructions for GitHub Desktop
	+ GitHub Student Developer Pack benefits
	+ Company background
	+ Database types (OLTP/DWH)
	+ Source databases: AdventureWorks, WideWorldImporters
	+ Target database setup
* Hands-on/Exercises:
	+ "Let's Practice" working with Git commands
	+ Database connection setup
	+ Create sample tables and import CSV data
	+ Upload files via browser and Storage Explorer
* Tools:
	+ GitHub
	+ Python (pandas, sklearn)

**Module 3: Data Engineering. Part 1**

* Topics:
	+ Data engineering introduction
	+ Data engineering & ML pipelines
	+ Data platform
	+ Zoning model
	+ Storage selection
	+ NoSQL databases
	+ Data platform architecture principles
	+ Architecture visualization
* Learning Objectives:
	+ Understand the definition and role of data engineering
	+ Learn about the relationship between data engineering and machine learning
	+ Comprehend the components of a data engineering pipeline
	+ Understand the concept of a data platform and its capabilities
	+ Learn about different zones in a data platform and their purposes
* Content:
	+ Definition of Data Engineering
	+ Role of Data Engineers in maintaining and preparing data infrastructure
	+ Diagram showing Data Engineering pipeline (Data Ingestion > Raw Data > Data Curation > Feature Engineering > Store)
	+ Machine Learning pipeline components
	+ Database connection setup
	+ Create sample tables and import CSV data
	+ Landing Zone, Raw Zone, Refined Zone, Usage Optimized Zone, Archive Zone, Sandbox Zone explanations
* Hands-on/Exercises:
	+ "Let's Practice" working with Git commands
	+ Database connection setup
	+ Create sample tables and import CSV data
	+ Upload files via browser and Storage Explorer
* Tools:
	+ GitHub
	+ Python (pandas, sklearn)

**Module 4: Advanced Data Science Topics**

* Topics:
	+ Introduction to machine learning
	+ Deep learning fundamentals
	+ Natural language processing
	+ Computer vision
	+ Recommender systems
* Learning Objectives:
	+ Understand the basics of machine learning and its applications
	+ Learn about deep learning architectures and their uses
	+ Comprehend the concepts of natural language processing and computer vision
	+ Understand how to build recommender systems using collaborative filtering and content-based methods
* Content:
	+ Introduction to supervised and unsupervised learning
	+ Regression, classification, clustering, and dimensionality reduction
	+ Deep learning frameworks such as TensorFlow and PyTorch
	+ Natural language processing techniques for text preprocessing and sentiment analysis
	+ Computer vision concepts for image recognition and object detection
	+ Recommender system algorithms and evaluation metrics
* Hands-on/Exercises:
	+ Build a simple machine learning model using scikit-learn
	+ Implement a deep learning model using TensorFlow or PyTorch
	+ Develop a natural language processing pipeline for text classification
	+ Create a computer vision application for image recognition
	+ Design and evaluate a recommender system for a given dataset
* Tools:
	+ Python (scikit-learn, TensorFlow, PyTorch)
	+ Jupyter Notebooks
	+ Google Colab

The Certificate of Advanced Studies in Data Engineering and Applied Data Science is designed to provide students with a comprehensive understanding of the concepts, tools, and techniques used in data engineering and applied data science. The program covers topics such as data science fundamentals, data engineering, machine learning, deep learning, natural language processing, computer vision, and recommender systems. Students will learn how to work with various tools and technologies, including Azure DevOps, GitHub, Python, and Jupyter Notebooks. The program includes hands-on exercises and projects that allow students to apply their knowledge and skills to real-world problems. Upon completion of the program, students will be equipped with the skills and knowledge needed to pursue a career in data engineering and applied data science.
